# 観察みくじ（仮）

今の状態を選ぶと、観察の問いが一枚出るページです。

## ファイルの役割

| ファイル | 中身 | 直すとき |
|---|---|---|
| `cards.txt` | カードの文面と、状態のボタン | 文面を変える・足す・消すときはここだけ |
| `images/` | カードの絵 | 番号つきの画像を置く |
| `index.html` | ページの見た目と仕組み | ふだんは触らなくてOK |

## カードの文面を直す（iPhone）

1. GitHubアプリ、またはSafariでこのリポジトリを開く
2. `cards.txt` を開いて、鉛筆マーク（Edit）をタップ
3. 書き換えたら「Commit changes」
4. 数分でページに反映されます

書き方：

```
[状態の名前]
タイトル｜問いの文
タイトル｜問いの文
```

- `[ ]` の行がボタンになります。増やしても減らしてもOK
- ボタンの中で改行したい位置には、空白を入れます（例：`[なんか　モヤモヤする]`）
- 区切りは「｜」（全角）でも「|」（半角）でもOK
- `#` で始まる行はメモ。ページには出ません
- カード番号は上から順に自動でつきます

## 絵を入れる

- `images` フォルダに、カード番号と同じ名前で画像を置きます
  - 例：No.06 のカード → `images/06.png`
  - 使える形式：png / jpg / jpeg / webp
- 置いていないカードは「絵が入る場所」と表示されます
- カードの順番を入れ替えると番号もずれるので、絵の名前も合わせて変えてください

## 触らないでほしいところ

- `index.html` の「しんどい」を選んだときの枠（相談窓口の案内）
- ページ下の「診断や治療ではありません」の表示

ここは安全のために、カードの編集とは別にしてあります。
